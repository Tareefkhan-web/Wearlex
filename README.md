# Aurum — Luxury Shoe Landing Page

Aurum is a modern, high-end 3D luxury shoe landing page built with modern web development frameworks. Designed for premium aesthetics, fast performance, and an immersive user experience.

---

## Key Features

* **3D Luxury Design:** High-end visual layout tailored for a luxury footwear showcase.
* **Responsive Layout:** Fully responsive across all devices (Mobile, Tablet, Desktop).
* **Modern UI/UX:** Smooth animations and intuitive component structures.

---

## Tech Stack

* **Framework:** Next.js
* **Library:** React
* **Styling:** Tailwind CSS
* **Deployment:** Vercel
